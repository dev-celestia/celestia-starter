Alpine UI

Interactive UI primitives built on Alpine.data(...) and styled with the same Celestia design tokens as @celestia-project/ui. Zero framework lock-in — drop it into HTML, Laravel Blade, Vite, or a static export.

Quick start 
import Alpine from "alpinejs"
import { alpineUI } from "@celestia-project/alpine-ui"

Alpine.plugin(alpineUI)
window.Alpine = Alpine
Alpine.start()

Then import @celestia-project/alpine-ui/globals.css in your stylesheet. Browse a component below to copy its markup.
