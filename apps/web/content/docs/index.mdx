Celestia Starter is a production-ready monorepo template with a decoupled architecture: a Hono backend that owns the data and auth, and a Next.js frontend that is pure UI.

## Tech Stack

- **Next.js 16** — Frontend (pure UI), App Router
- **Hono** — Standalone backend API (owns DB + auth + business logic)
- **Better Auth** — Email/password + OAuth authentication (runs on the backend)
- **Drizzle ORM** — Type-safe PostgreSQL queries and migrations
- **Hono RPC** — End-to-end typed API calls from frontend to backend
- **Tailwind CSS v4 + @celestia-project/ui** — Utility-first styling with 150+ accessible components
- **Turborepo + pnpm workspaces** — Fast monorepo builds and workspace management

## Project Structure

```
celestia-starter/
├── apps/
│   ├── web/               # Next.js frontend (pure UI, landing, showcase, docs)
│   │   └── content/docs/  # Documentation pages (MDX)
│   ├── api/               # Hono backend (auth + data + business logic)
│   └── mobile/            # Expo showcase app for @celestia-project/mobile
├── packages/
│   ├── db/                # Drizzle schema + client (backend-only)
│   ├── ui/                # Shared component library (Base UI + Tailwind v4)
│   ├── mobile/            # Native components (@expo/ui for iOS & Android)
│   ├── cli/               # @celestia-project/create CLI package
│   ├── feature-manager/   # CLI & installer engine for modular features
│   ├── eslint-config/     # Shared ESLint flat-config presets
│   └── typescript-config/ # Shared TypeScript configs
```

## Getting Started

```bash
# Using the CLI
npx @celestia-project/create my-app

# Or clone manually
pnpm install
pnpm --filter @workspace/db db:push   # create the database schema
pnpm dev                               # starts web (port 1212) + api (port 4000)
```
