Celestia Starter is a production-ready monorepo template with a decoupled architecture: a Hono backend that owns the data and auth, and a Next.js frontend that is pure UI.

## Tech Stack

- **Next.js 15** — Frontend (pure UI), App Router
- **Hono** — Standalone backend API (owns DB + auth + business logic)
- **Better Auth** — Email/password + OAuth authentication (runs on the backend)
- **Drizzle ORM** — Type-safe PostgreSQL queries and migrations
- **Hono RPC** — End-to-end typed API calls from frontend to backend
- **Tailwind CSS v4 + @celestia-project/ui** — Utility-first styling with 60+ accessible components
- **Turborepo + pnpm workspaces** — Fast monorepo builds and workspace management

## Project Structure

```
celestia-starter/
├── apps/
│   ├── web/          # Next.js frontend (pure UI, no database access)
│   ├── api/          # Hono backend (auth + data + business logic)
│   └── docs/         # This documentation site (Fumadocs)
├── packages/
│   ├── db/           # Drizzle schema + client (backend-only)
│   ├── ui/           # Shared shadcn/ui component library
│   ├── eslint-config/
│   ├── typescript-config/
│   └── feature-manager/  # CLI for installing features
└── features/         # Installable feature modules
```

## Getting Started

```bash
# Using the CLI
npx @celestia-project/create my-app

# Or clone manually
pnpm install
pnpm --filter @workspace/db db:push   # create the database schema
pnpm dev                               # starts web + api + docs
```
