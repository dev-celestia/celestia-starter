# Desktop AI

GPUI counterparts of `packages/ui/src/components/ai/*.tsx`, under
`celestia_ui::components::ai`. Host apps own streaming / `Entity` state; these
builders take callbacks and element slots.

Run the gallery → **Chat & AI**:

```bash
pnpm desktop
```

Flat imports work for most types (`use celestia_ui::components::PromptInput`).
Prefer `AiCodeBlock` / `AiTerminal` / `AiConfirmation` — they avoid clashes with
composite `CodeBlock` and similar names.

Existing conversation primitives stay under composite/primitive:
`Message`, `Bubble`, `Attachment`, `MessageScroller`, `Marker`, `Avatar`.

## Thinking / shimmer text

Animated status while the model is working. `ThinkingText` is the AI chrome
(brain icon + wave shimmer + cycling dots). `ShimmerText::wave` is the raw
travelling-band label (web `ai/shimmer.tsx` counterpart).

```rust
use celestia_ui::components::ai::thinking_text::ThinkingText;
use celestia_ui::components::primitive::shimmer::ShimmerText;

ThinkingText::new("status");                    // “Thinking” + dots
ThinkingText::new("search").label("Searching");

ShimmerText::wave("Generating a response…");    // travelling highlight
ShimmerText::new("Loading…");                   // whole-label pulse
```

`Reasoning::streaming(true)` swaps the header for `ThinkingText` automatically.

## Quick start

```rust
use celestia_ui::components::ai::prompt_input::{PromptInput, PromptStatus};
use celestia_ui::components::ai::reasoning::Reasoning;
use celestia_ui::components::ai::suggestion::{Suggestion, Suggestions};
use celestia_ui::components::ai::tool::{Tool, ToolState};
use celestia_ui::components::ai::plan::{Plan, PlanStep, PlanStepStatus};

Suggestions::new("sugs")
    .child(Suggestion::new("s1", "Explain this diff"))
    .child(Suggestion::new("s2", "Write a unit test"));

PromptInput::new("prompt")
    .placeholder("Ask Celestia…")
    .status(PromptStatus::Ready)
    .on_submit(|_, _, cx| { /* send */ cx.notify(); });

Reasoning::new("think")
    .open(true)
    .duration_secs(3)
    .body("Comparing desktop and web message metrics…");

Tool::new("read", "read_file").state(ToolState::Completed);

Plan::new("plan", "Ship AI gallery")
    .child(PlanStep::new("p1", "Scaffold module").status(PlanStepStatus::Done))
    .child(PlanStep::new("p2", "Wire demos").status(PlanStepStatus::Active));
```
