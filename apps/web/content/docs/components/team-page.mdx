The team directory: a roster of members beside an invite panel.

The invite panel is a slot rather than a built-in form, because an invite is where a product's rules live — seat limits, domain allow-lists, role defaults. A layout that guessed at them would be a layout every consumer immediately replaces.

```tsx
import { TeamPage, Button, Input, Label } from "@/components/layout-templates/team-page"
import type { TeamMember } from "@/components/layout-templates/team-page"

const members: TeamMember[] = [
  { id: "t1", name: "Ada Lin", email: "ada@northwind.dev", role: "Owner", status: "active", avatarFallback: "AL" },
  { id: "t2", name: "Ravi Shah", email: "ravi@northwind.dev", role: "Member", status: "invited", avatarFallback: "RS" },
]

<TeamPage
  title="Team"
  description="9 of 12 seats used on the Team plan."
  members={members}
  actions={<Button size="sm">Invite</Button>}
  onMemberClick={(id) => router.push(`/team/${id}`)}
  invite={
    <>
      <Label htmlFor="email">Email address</Label>
      <Input id="email" type="email" placeholder="name@company.com" />
      <Button className="w-full">Send invitation</Button>
    </>
  }
/>
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `members` | `TeamMember[]` | — (required) | `{ id, name, email, role, status, avatarFallback? }` |
| `invite` | `React.ReactNode` | — | Invite panel; the column disappears when omitted |
| `onMemberClick` | `(id: string) => void` | — | Fired when a row is activated |

Plus every [PageShell](/docs/components/page-shell) prop.

`status` is `"active" | "invited" | "suspended"`, mapped to `success`, `warning` and `secondary` badges. The Role column drops out below `sm`, but Status stays at every width — it is the one column that changes what you can do with a row.
