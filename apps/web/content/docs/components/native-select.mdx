A styled native `<select>` — the best choice when the browser picker (mobile, autofill) is preferred.

<NativeSelectPreview />

```tsx
import {
  NativeSelect,
  NativeSelectOption,
} from "@celestia-project/ui/components/native-select"

<NativeSelect aria-label="Fruit">
  <NativeSelectOption value="apple">Apple</NativeSelectOption>
  <NativeSelectOption value="banana">Banana</NativeSelectOption>
</NativeSelect>
```

`NativeSelectOptGroup` groups options.
