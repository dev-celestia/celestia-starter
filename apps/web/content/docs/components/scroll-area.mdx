A custom-styled scrollable region, built on the Base UI `ScrollArea` primitive.

<ScrollAreaPreview />

```tsx
import { ScrollArea } from "@celestia-project/ui/components/scroll-area"

<ScrollArea className="h-36 rounded-md border p-4">
  {/* long content */}
</ScrollArea>
```

`ScrollBar` with `orientation="horizontal"` adds a horizontal scrollbar.
