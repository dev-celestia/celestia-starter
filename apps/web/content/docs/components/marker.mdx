Visual indicator badge or dot for highlighting status, changes, or focus points.

```tsx
import { Marker } from "@celestia-project/ui/components/marker"

<Marker variant="default">New</Marker>
<Marker variant="destructive" />
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline"` | `"default"` | Styling variant |
| `className` | `string` | `undefined` | Custom CSS class overrides |
