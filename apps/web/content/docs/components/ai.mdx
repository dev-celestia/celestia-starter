The `@celestia-project/ui` library ships with a comprehensive suite of **54 production-ready AI components** built to power generative AI applications, agent workflows, LLM chat interfaces, multi-modal audio/speech interactions, and live sandbox executions.

All AI components are fully styled with Tailwind CSS v4, support light and dark theme OKLCH tokens, and provide keyboard and screen-reader accessibility.

---

## Installation & Import Conventions

You can import AI components from the main package barrel `@celestia-project/ui` or via deep imports `@celestia-project/ui/components/ai/<name>`:

```tsx
// Package root import
import {
  PromptInput,
  Reasoning,
  Tool,
  ModelSelector,
  Plan,
  Task,
} from "@celestia-project/ui"

// Dedicated AI submodule import
import {
  PromptInput,
  Reasoning,
  Tool,
} from "@celestia-project/ui/ai"

// Deep component import
import { PromptInput } from "@celestia-project/ui/components/ai/prompt-input"
```

## Component Taxonomy

The 54 AI components are organized into 6 core functional domains:

### 1. Prompts, Inputs & Voice

| Component | Description |
| --- | --- |
| [`prompt-input`](/docs/components/prompt-input) | Expandable AI prompt bar with file dropzone, model selector, tool buttons, and action menu. |
| [`chat-input`](/docs/components/chat-input) | Auto-resizing textarea specialized for standard chat input prompts. |
| [`speech-input`](/docs/components/speech-input) | Microphone voice recording input with real-time waveform visualizer. |
| [`suggestion`](/docs/components/suggestion) | Quick-prompt recommendation pills and action chips. |
| [`mic-selector`](/docs/components/mic-selector) | Input audio device selection dropdown. |
| [`voice-selector`](/docs/components/voice-selector) | Voice profile picker with audio test samples and gender indicators. |

### 2. Chat & Streaming Message Experience

| Component | Description |
| --- | --- |
| [`message`](/docs/components/message) | Full-featured message container with markdown rendering, branching history, and action toolbars. |
| [`chat-message`](/docs/components/chat-message) | Role-based message container (user vs assistant) with distinct styling. |
| [`chat-message-area`](/docs/components/chat-message-area) | Message feed scroll layout with automatic message stacking. |
| [`message-scroller`](/docs/components/message-scroller) | Sticky auto-scrolling viewport with pinned bottom stream anchor. |
| [`conversation`](/docs/components/conversation) | Complete chat conversation feed with empty states and scroll buttons. |
| [`bubble`](/docs/components/bubble) | Chat speech bubble with sentiment reactions and tail variants. |
| [`shimmer`](/docs/components/shimmer) | Loading placeholder shimmer text animation during LLM token streaming. |
| [`open-in-chat`](/docs/components/open-in-chat) | Quick-launch menu to transfer prompts directly to ChatGPT, Claude, or Perplexity. |
