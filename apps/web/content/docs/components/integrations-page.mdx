> **Copy template.** This layout ships as a source file, not a package export. Copy it from [`/layout/integrations-page`](/layout/integrations-page) or `apps/web/components/layout-templates/integrations-page.tsx`, then paste it into your app and adjust freely.

The integrations directory: category chips over a grid of connectable apps.

Toggling is uncontrolled by default — each card keeps its own optimistic state and reports the change upward. Wiring the switch to a controlled prop would make every toggle wait on a round trip, and the connection state here is the *last known* one, not the authoritative one.

```tsx
import { IntegrationsPage } from "@/components/layout-templates/integrations-page"
import type { Integration } from "@/components/layout-templates/integrations-page"

const integrations: Integration[] = [
  {
    id: "slack",
    name: "Slack",
    description: "Post build and release events to a channel.",
    category: "Communication",
    connected: true,
    icon: <SlackLogoIcon />,
  },
  {
    id: "figma",
    name: "Figma",
    description: "Pull tokens and frames into the catalogue.",
    category: "Design",
    connected: false,
    icon: <FigmaLogoIcon />,
  },
]

export function AppsPage() {
  const [category, setCategory] = useState("All")

  return (
    <IntegrationsPage
      title="Integrations"
      description="Connect the tools your team already uses."
      categories={["All", "Communication", "Code", "Design", "Finance"]}
      activeCategory={category}
      onCategoryChange={setCategory}
      integrations={integrations.filter((i) => category === "All" || i.category === category)}
      onConnectionChange={(id, connected) => mutate({ id, connected })}
    />
  )
}
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `integrations` | `Integration[]` | — (required) | `{ id, name, description, category, connected?, icon? }` |
| `categories` | `string[]` | — | Category chips; omit to hide the filter row |
| `activeCategory` / `onCategoryChange` | `string` / `(c) => void` | — | Controlled chip selection |
| `onConnectionChange` | `(id, connected) => void` | — | Fired with the integration id and its next state |

Plus every [PageShell](/docs/components/page-shell) prop.

The callback is `onConnectionChange` rather than `onToggle` because `React.ComponentProps<"div">` already declares an `onToggle` DOM handler and the two signatures clash. Cards fall back to the app's first letter when `icon` is omitted, and the grid is three-up from `xl`.
