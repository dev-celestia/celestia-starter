A menu shown on right-click, built on the Base UI `ContextMenu` primitive.

<ContextMenuPreview />

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
  ContextMenuShortcut,
  ContextMenuTrigger,
} from "@celestia-project/ui/components/context-menu"

<ContextMenu>
  <ContextMenuTrigger>Right click here</ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem>
      Reload
      <ContextMenuShortcut>⌘R</ContextMenuShortcut>
    </ContextMenuItem>
    <ContextMenuSeparator />
    <ContextMenuItem variant="destructive">Delete</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```

Sub-menus, checkbox items, radio groups and groups are available via `ContextMenuSub`, `ContextMenuCheckboxItem`, `ContextMenuRadioGroup`, and `ContextMenuGroup`.
