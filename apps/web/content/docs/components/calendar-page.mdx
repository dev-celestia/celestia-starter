The month calendar: a seven-column grid with a day-detail rail.

Every date value arrives pre-computed — `monthLabel`, each day's `date`, and the agenda's `time` are all strings or plain numbers. Building the grid here would mean owning a calendar library's locale, week-start and timezone rules, and the consumer almost always already has a date library for exactly that.

```tsx
import { CalendarPage } from "@/components/layout-templates/calendar-page"

export function SchedulePage() {
  const [day, setDay] = useState("d9")

  return (
    <CalendarPage
      title="Schedule"
      description="Sprint 24 — design system."
      monthLabel="October 2026"
      weekdays={["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]}
      days={[
        { id: "d1", date: 28, outside: true },
        { id: "d2", date: 1, events: [{ id: "e1", title: "Design review", tone: "info" }] },
        {
          id: "d3",
          date: 6,
          today: true,
          events: [
            { id: "e2", title: "Standup", tone: "info" },
            { id: "e3", title: "Release cut", tone: "destructive" },
          ],
        },
      ]}
      agenda={[
        { id: "a1", time: "09:00", title: "Standup", meta: "Design system", tone: "info" },
      ]}
      selectedDayId={day}
      onSelectDay={setDay}
    />
  )
}
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `monthLabel` | `string` | — (required) | Already-formatted month, e.g. `"October 2026"` |
| `weekdays` | `string[]` | — (required) | Seven column headings, starting on your week's first day |
| `days` | `CalendarDay[]` | — (required) | Grid cells in reading order |
| `agenda` | `CalendarAgendaItem[]` | — | The selected day's schedule, shown in the rail |
| `selectedDayId` / `onSelectDay` | `string` / `(id) => void` | — | Controlled day selection |

Plus every [PageShell](/docs/components/page-shell) prop.

`CalendarDay` is `{ id, date: number, outside?, today?, events? }`; `CalendarAgendaItem` is `{ id, time, title, meta?, tone? }`. A cell shows at most two event chips and collapses the rest into a `+N more` line, so a busy day cannot push the row height out of the grid.
