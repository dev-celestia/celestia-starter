> **Copy template.** This layout ships as a source file, not a package export. Copy it from [`/layout/reset-password-page`](/layout/reset-password-page) or `apps/web/components/layout-templates/reset-password-page.tsx`, then paste it into your app and adjust freely.

A set-new-password screen on the [AuthShell](/docs/components/auth-shell) frame: new password + confirmation with live mismatch feedback, and a submit that stays disabled until the pair agrees. Token handling stays at the call site — pass it to your auth client inside `onSubmit`.

<ResetPasswordPagePreview />

```tsx
import { ResetPasswordPage } from "@/components/layout-templates/reset-password-page"

<ResetPasswordPage
  onSubmit={({ password }) => {
    // auth.resetPassword({ password, token })
  }}
  loading={false}
/>
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onSubmit` | `({ password, confirmPassword }) => void` | — | Form submit handler |
| `loading` | `boolean` | `false` | Disables the form and shows progress on the submit button |
| `error` | `string` | — | Inline error banner above the fields |
| `heading` / `subheading` | `string` | `"Set a new password"` / … | Copy overrides |
| `passwordLabel` / `confirmPasswordLabel` / … | `string` | `"New password"` / … | Label and placeholder overrides |
