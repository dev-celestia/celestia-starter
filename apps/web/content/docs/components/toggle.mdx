A two-state button that can be on or off, built on the Base UI `Toggle` primitive.

<TogglePreview />

```tsx
import { Toggle } from "@celestia-project/ui/components/toggle"

<Toggle aria-label="Toggle bold">B</Toggle>
<Toggle aria-label="Toggle italic" variant="outline">I</Toggle>
```

| Prop | Type | Default |
|------|------|---------|
| `variant` | `default \| outline` | `default` |
| `size` | `default \| sm \| lg` | `default` |
