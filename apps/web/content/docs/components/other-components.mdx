The package also ships these utility and composite components:

| Component | Import | Notes |
|-----------|--------|-------|
| `form` | `@celestia-project/ui/composite/form` | `react-hook-form` integration: `Form`, `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormDescription`, `FormMessage`, `useFormField` |
| `data-table` | `@celestia-project/ui/composite/data-table` | Typed data table component built on `@tanstack/react-table` with sorting, filtering, and pagination |
| `ripple` | `@celestia-project/ui/primitive/ripple` | `Ripple` click effect component for touch and mouse interactions |
| `article-card` | `@celestia-project/ui/composite/article-card` | Media and blog post card composite with author, date, and tag metadata |
| `tab-bar` | `@celestia-project/ui/composite/tab-bar` | Mobile-friendly segmented tab bar navigation |
| `select-env-input` | `@celestia-project/ui/composite/select-env-input` | Environment selector dropdown and input composite |
