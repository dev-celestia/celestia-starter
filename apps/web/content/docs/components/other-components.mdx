The package also ships these components without live previews on this page:

| `bubble` | `@celestia-project/ui/primitive/bubble` | Chat message speech bubble primitive |
| `attachment`, `marker`, `message`, `message-scroller` | `@celestia-project/ui/composite/<name>` | Chat/AI message UI composites |
