> **Copy template.** This layout ships as a source file, not a package export. Copy it from [`/layout/forgot-password-page`](/layout/forgot-password-page) or `apps/web/components/layout-templates/forgot-password-page.tsx`, then paste it into your app and adjust freely.

A password recovery request screen on the [AuthShell](/docs/components/auth-shell) frame. Flip the `sent` prop once your auth client has dispatched the reset link, and the form swaps to a confirmation message — no routing required.

<ForgotPasswordPagePreview />

```tsx
import { ForgotPasswordPage } from "@/components/layout-templates/forgot-password-page"

export function ForgotPasswordScreen() {
  const [sent, setSent] = React.useState(false)

  return (
    <ForgotPasswordPage
      sent={sent}
      onSubmit={({ email }) => {
        // auth.forgetPassword({ email })
        setSent(true)
      }}
      onBack={() => setSent(false)}
    />
  )
}
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onSubmit` | `({ email }) => void` | — | Form submit handler |
| `sent` | `boolean` | `false` | Swaps the form for the confirmation message |
| `sentMessage` | `string` | `"Check your inbox — …"` | Confirmation copy shown when `sent` |
| `onBack` | `() => void` | — | Renders the "Back to sign in" footer link when set |
| `backLabel` | `string` | `"Back to sign in"` | Back-link copy |
| `loading` / `error` | `boolean` / `string` | `false` / — | Pending and error states |
