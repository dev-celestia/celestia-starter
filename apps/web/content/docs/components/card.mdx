A composable container with header, content, and footer regions.

<CardPreview />

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@celestia-project/ui/components/card"

<Card>
  <CardHeader>
    <CardTitle>Create project</CardTitle>
    <CardDescription>Deploy your new project in one-click.</CardDescription>
    <CardAction>{/* optional action button */}</CardAction>
  </CardHeader>
  <CardContent>{/* body content */}</CardContent>
  <CardFooter>{/* footer actions */}</CardFooter>
</Card>
```

| Component | Purpose |
|-----------|---------|
| `Card` | Root container (accepts `size="default" \| "sm"`) |
| `CardHeader` | Title/description region |
| `CardTitle` | Heading text |
| `CardDescription` | Supporting text |
| `CardAction` | Top-right action slot |
| `CardContent` | Body region |
| `CardFooter` | Bottom action region |
