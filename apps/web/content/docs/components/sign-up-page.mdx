> **Copy template.** This layout ships as a source file, not a package export. Copy it from [`/layout/sign-up-page`](/layout/sign-up-page) or `apps/web/components/layout-templates/sign-up-page.tsx`, then paste it into your app and adjust freely.

A complete registration screen on the [AuthShell](/docs/components/auth-shell) frame: name, email, password and confirmation fields, with a live mismatch check on the password pair and an optional terms checkbox that gates submission.

```tsx
import { SignUpPage } from "@/components/layout-templates/sign-up-page"

<SignUpPage
  termsLabel="I agree to the terms and privacy policy"
  onSignIn={() => {
    // router.push("/sign-in")
  }}
  onSubmit={({ name, email, password }) => {
    // auth.signUp.email({ name, email, password })
  }}
/>
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onSubmit` | `({ name, email, password, confirmPassword, termsAccepted }) => void` | — | Form submit handler |
| `termsLabel` | `React.ReactNode` | — | Renders the terms checkbox with this label; omit to hide the gate |
| `onTermsChange` | `(accepted: boolean) => void` | — | Terms checkbox change handler |
| `onSignIn` | `() => void` | — | Footer sign-in link handler |
| `loading` | `boolean` | `false` | Disables the form and shows progress on the submit button |
| `error` | `string` | — | Inline error banner above the fields |
| `nameLabel` / `emailLabel` / … | `string` | `"Full name"` / … | Label and placeholder overrides |

The submit is a no-op until the password and confirmation agree, and — when `termsLabel` is set — until the terms checkbox is ticked.
