# Celestia Design System

The Celestia Design System is a production-grade, accessible UI foundation packaged under [`@celestia-project/ui`](https://www.npmjs.com/package/@celestia-project/ui). It combines unstyled **Base UI** primitives with **Tailwind CSS v4** design tokens defined in the **OKLCH** color space.

---

## Architectural Principles

1. **Unstyled Primitives (Base UI)**: All interactive components (Dialog, DropdownMenu, Tabs, Tooltip, Select) inherit WAI-ARIA compliance, screen reader support, focus-trapping, and keyboard navigation directly from Base UI.
2. **OKLCH Color Tokens**: Colors are authored in perceptual OKLCH coordinates to maintain consistent perceived brightness and contrast ratios across light and dark themes.
3. **Zero-Runtime Styling**: All styles map to CSS custom properties (`var(--primary)`, `var(--radius)`). No JavaScript runtime overhead or CSS-in-JS style injection.
4. **Decoupled & External Ready**: Packaged as an ESM module with deep import paths (`@celestia-project/ui/components/button`) and strict TypeScript types.

---

## Consuming in External Projects

You can install and use the design system in any Next.js, Vite, Remix, or React 19 application.

### 1. Installation

```bash
pnpm add @celestia-project/ui @phosphor-icons/react @base-ui/react
# or
npm install @celestia-project/ui @phosphor-icons/react @base-ui/react
```

**Peer Dependencies:** Requires `react@^19` and `react-dom@^19`.

---

### 2. Import Global Stylesheet

In your application's root entry point (e.g. `app/layout.tsx` for Next.js App Router or `src/main.tsx` for Vite):

```tsx
import "@celestia-project/ui/globals.css";
```

This brings in all OKLCH design tokens, CSS variable definitions, base reset styles, and animations.

---

### 3. Setup Dark Mode & Theme

The design system uses standard class-based dark mode (`.dark`):

```tsx
// Next.js App Router layout.tsx
import "@celestia-project/ui/globals.css";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className="dark">
      <body className="bg-background text-foreground antialiased min-h-screen">
        {children}
      </body>
    </html>
  );
}
```

---

### 4. Component Usage

You can import components directly via the barrel export or use granular deep imports for minimal bundle size:

```tsx
import { Button, Card, CardHeader, CardTitle, CardContent, Badge } from "@celestia-project/ui";
import { SparkleIcon } from "@phosphor-icons/react";

export function WelcomeCard() {
  return (
    <Card className="max-w-md">
      <CardHeader>
        <div className="flex items-center justify-between">
          <CardTitle>Celestia UI</CardTitle>
          <Badge variant="outline" className="gap-1 text-primary">
            <SparkleIcon className="size-3" weight="fill" /> Ready
          </Badge>
        </div>
      </CardHeader>
      <CardContent className="space-y-4">
        <p className="text-sm text-muted-foreground">
          Zero-runtime design tokens coupled with accessible Base UI primitives.
        </p>
        <Button variant="default">Get Started</Button>
      </CardContent>
    </Card>
  );
}
```

| Subpath | Resolves To | Description |
|---|---|---|
| `@celestia-project/ui` | `src/index.ts` | Complete barrel export of all 70+ components |
| `@celestia-project/ui/globals.css` | `src/styles/globals.css` | CSS tokens & root styles |

## Token Reference

### Colors (OKLCH)

| Token Variable | Tailwind Utility | Light Value | Dark Value |
|---|---|---|---|
| `--background` | `bg-background` | `oklch(1 0 0)` | `oklch(0.145 0 0)` |
| `--foreground` | `text-foreground` | `oklch(0.145 0 0)` | `oklch(0.985 0 0)` |
| `--primary` | `bg-primary` | `oklch(0.205 0 0)` | `oklch(0.985 0 0)` |
| `--primary-foreground` | `text-primary-foreground` | `oklch(0.985 0 0)` | `oklch(0.205 0 0)` |
| `--muted` | `bg-muted` | `oklch(0.97 0 0)` | `oklch(0.269 0 0)` |
| `--muted-foreground` | `text-muted-foreground` | `oklch(0.556 0 0)` | `oklch(0.708 0 0)` |
| `--destructive` | `bg-destructive` | `oklch(0.577 0.245 27.325)` | `oklch(0.396 0.141 25.723)` |
| `--border` | `border-border` | `oklch(0.922 0 0)` | `oklch(0.269 0 0)` |
| `--ring` | `ring-ring` | `oklch(0.708 0 0)` | `oklch(0.439 0 0)` |

### Radii Scale

All radii inherit mathematically from `--radius` (`0.625rem` / `10px`):

- **Small (`rounded-sm`)**: `calc(var(--radius) - 4px)` (~4px) — Badges, tooltips, small chips.
- **Medium (`rounded-md`)**: `calc(var(--radius) - 2px)` (~6px) — Form controls, buttons, dropdown rows.
- **Large (`rounded-lg`)**: `var(--radius)` (~8px) — Cards, modal dialogs, drawers.
- **Extra Large (`rounded-xl`)**: `calc(var(--radius) + 4px)` (~12px) — Floating banners, hero surfaces.
- **Full (`rounded-full`)**: `9999px` — Avatars, status indicators, pill buttons.
